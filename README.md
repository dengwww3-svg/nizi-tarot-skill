# 尼子塔羅 Nizi Tarot

在同一段聊天中完成選題、確認抽牌、展示標準韋特牌圖、逐位解讀與補牌追問的 AI Skill。無須另外開啟占卜網站或註冊帳號。

預設以溫柔、清楚的繁體中文回覆，也可依使用者要求切換語言。塔羅用於自我探索與娛樂，不保證未來，也不能證實他人的內心。

## 可以做什麼

- **不同主題**：感情、復合、工作、人際、兩難選擇、自我探索。
- **依問題選牌陣**：1～10張，包含三張牌、六張關係陣、五張選擇陣、九張復合陣與凱爾特十字。
- **兩種抽牌方式**：程式隨機，或先洗牌再由使用者選1～78的數字；等使用者確認後才揭牌。
- **固定韋特牌圖**：內附78張歷史韋特牌圖，依牌陣排成靜態圖片；逆位旋轉180度，文字標籤保持正向。
- **直接解讀**：揭牌後立即解釋牌義、正逆位與牌位，不需要再輸入一次「幫我解讀」。
- **清楚總結**：結尾提供「偏正向／偏負向／正負並存、暫不明朗」，說明依據及一個行動建議。
- **補牌與追問**：沿用原牌回答後續問題；明確要求補牌時，每次1～3張，沿用原副剩餘牌、不重複、不覆蓋原牌。
- **外部牌面**：使用者可提供牌名或清楚照片，由 AI 解讀；數位補牌與實體牌的來源會分開說明。
- **日曆主題**：生日、情人節、520、七夕、長假前、假後收心、月度與年末整理。

## 快速開始

在已載入此 Skill 的 AI 對話中輸入：

> 使用尼子塔羅。我和對方已分開、沒有聯絡，想看看近期的關係與未來一個月重新互動的空間。

AI 會先推薦牌陣與牌位。接著回覆：

> 開始。

或者選擇數字抽牌：

> 我想自己選。

AI 先建立固定牌堆，再請你輸入對應張數的互異數字。解讀後可以繼續：

> 補一張，看我主動聯絡需要注意什麼。

以上只是操作範例，沒有預先指定牌面或結果。沒有工具時，AI 必須明說採用文字模擬，不能冒充程式隨機。

## 首次使用與主動提醒

第一次可說「你好」，或直接提問；有具體問題就先占卜，生日設定不會擋住流程。生日與提醒都可跳過。

簡短設定範例：

> 我想開啟生日和七夕提醒。生日是公曆6月18日，生日當天上午9點提醒；七夕提前3天上午9點提醒，時區是 Asia/Shanghai。

這是示例日期，不是預填給所有人的設定。生日只收月、日，不要求出生年份；支援公曆／農曆，農曆另確認是否為閏月。使用者自行選擇提醒類別，不預設全部開啟。

**主動通知必須由宿主平台提供排程能力。** Skill 文件本身不會背景執行，不附通用通知伺服器，也不會因為上傳 GitHub 就開始發通知。AI 只有在實際建立任務成功後，才能回覆「已設定」。無排程工具時，只能在使用者回來聊天時推薦近期主題。

- 公開節日資料可用來核對日期，不必讀取私人行事曆。
- 若要讀取私人行事曆，仍需宿主的日曆連接、帳號授權與使用者提出的需求。
- 七夕、農曆生日與官方連休要依目標年份核對；不能每年沿用同一公曆日期。
- 2月29日、農曆閏月或缺少30日等情況，先確認替代規則，不自行決定。
- 提醒只邀請使用者回來；當次先了解近況／假期安排，等本人確認後才抽牌。
- 沒有可持續儲存的私有記憶時，不宣稱能跨聊天、跨 AI 記住設定。

詳細規則見 [生日與提醒](references/onboarding-reminders.md)、[日曆模式](references/calendar-modes.md)。

## 安裝與平台相容性

將整個資料夾交給支援 Skill 的宿主平台載入，**不要只複製 SKILL.md**，否則參考規則、圖片與腳本會缺失。資料夾名稱建議保留為 `nizi-tarot`。

Codex 本機環境可將資料夾放在 `~/.codex/skills/nizi-tarot/`；若自訂 `CODEX_HOME`，則使用該目錄下的 `skills/nizi-tarot/`。確認根目錄可直接找到 SKILL.md，再由宿主重新載入技能。

內部平台或其他 AI 請依其實際 Skill 匯入方式處理。此專案提供可攜的 Markdown 規則與 Python 腳本，**不是一個能自動替所有 AI 增加工具的應用程式**。

| 宿主能力 | 可用體驗 |
| --- | --- |
| 只有文字 | 問題分析、文字模擬／外部牌面解讀、總結與追問 |
| Python 3.9以上＋私有臨時目錄 | 固定牌堆、程式隨機、數字選牌與同局補牌 |
| 再加 Pillow＋附件顯示 | 標準牌圖與靜態牌陣 |
| 網路或可靠曆法工具 | 核對未內建年份的節日與農曆日期 |
| 私有記憶／排程工具 | 依實際支援能力保存偏好、建立與修改提醒 |

核心對話不綁定模型品牌；圖片、真隨機、記憶與提醒是否可用，取決於宿主。無對應能力時必須如實降級，不能保證所有 AI 的執行效果完全相同。

## 開發與驗證

在本資料夾執行：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

抽牌及日曆腳本只使用 Python 標準函式庫；Pillow 用於排圖及圖像測試。腳本使用方式見 [會話指南](references/session-guide.md) 與 [牌圖指南](references/cards-and-images.md)。

日曆腳本目前內建2026年中國大陸連休／補班資料，以及2026、2027年的七夕日期。其他年份或地區會標示待核實，不能視為已涵蓋所有日曆。

目前包含34項自動測試，涵蓋78張牌唯一性、選牌順序、錯誤不改牌堆、補牌不重複、狀態恢復、日期邊界、牌圖對應、各種排版與逆位旋轉。這些測試不代表已驗證每一種 AI 或內部平台。

## 上傳 GitHub

建議倉庫名稱：`nizi-tarot`。將本資料夾內的檔案上傳至倉庫根目錄，讓 GitHub 首頁直接顯示 README.md，並能在根目錄找到 SKILL.md、assets、references、scripts。

若使用下載的封存檔，先解壓再上傳內容，不要只把封存檔放進倉庫。請保留78張圖片、字體授權及來源說明；不要上傳個人抽牌狀態、生日、提醒任務ID、帳號憑證或開發工作區。
